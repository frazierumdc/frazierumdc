## How I build

- **Claude judges, code calculates.** The model makes the judgment calls. Code does the arithmetic, and every answer is checked.
- **Security is designed in, not bolted on.** Guardrails, tests and documentation are part of the build from the start.
- **Decisions are written down.** Each one gets options, trade-offs and a recommendation.
